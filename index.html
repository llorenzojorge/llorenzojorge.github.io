sobre

Um dev full-stack que pensa primeiro no back-end: dados certos, regras claras, código testado.

Comecei em TI pelo suporte e pela infraestrutura, atendendo professores, alunos e equipe todos os dias. Foi ali que aprendi a enxergar o sistema do lado de quem usa: o que quebra, o que confunde e o que faz perder tempo.

Hoje levo esse olhar para o código. Construo APIs REST com Node.js, NestJS e .NET, interfaces com Next.js e React, e estudo Sistemas de Informação. Busco um time onde eu possa assumir responsabilidade cedo e crescer rápido.

projetos

01 · api rest

estoque-lotes-api

Controle de estoque e validade de lotes de alimentos perecíveis, com rastreabilidade de cada entrada e saída.

  • Lote vencido não sai: regra no Service e CHECK no banco como última barreira
  • Movimentação e saldo gravados na mesma transação
  • Erros no padrão ProblemDetails (RFC 9457), testes com xUnit e CI

C# · .NET 8 · SQL Server · EF Core · Dapper · Docker

02 · api rest

rocketlog

API de entregas de encomendas, com autenticação e permissões por papel de usuário.

  • Autenticação JWT e autorização por papel (customer / sale)
  • Status da entrega processing → shipped → delivered, com histórico em logs
  • Validação de entrada com Zod e tratamento centralizado de erros

TypeScript · Express · Prisma · PostgreSQL · JWT · Zod

ver código ↗

PATCH /deliveries/:id/status

Authorization: Bearer <jwt> // role: sale

{ "status": "shipped" }

200 OK

processing→shipped→delivered
